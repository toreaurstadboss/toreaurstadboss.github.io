## Preview locally

GitHub Pages builds this site with Jekyll. To preview it on Windows, install [RubyInstaller with Devkit](https://rubyinstaller.org/) and complete its MSYS2 setup, then run in PowerShell from the repository root:

```powershell
gem install github-pages webrick
jekyll serve --host 127.0.0.1
```

Open the [lecture 3 menu](http://127.0.0.1:4000/lectures/lecture3/Snowstorm.html). Jekyll rebuilds changed pages while running; restart it after changing `_config.yml`. Press `Ctrl+C` to stop the preview. The blog images in lecture 3 require an internet connection.
