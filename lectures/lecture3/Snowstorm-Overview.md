# A Local SNOMED CT Server

- **SNOMED CT** is a clinical terminology for representing healthcare concepts.
- **Snowstorm** is an open-source terminology server built on Elasticsearch.
- **RF2** (Release Format 2) is the distribution format used to load SNOMED CT content.

## Our goal

Run Snowstorm and Elasticsearch with Docker Compose, import an RF2 release, and query a concept locally.
